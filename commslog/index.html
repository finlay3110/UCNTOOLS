Welcome to UCN Comms Log

A quick rundown before you start logging
  1. Briefing — fill in the mission details: operative, ship, flight controller, date/time, and captain. This heads up the PDF report.
  2. Log — every transmission from every ship, merged in time order.
  3. Ships — log a new ship, or tap an existing one (UCS Warspite is there by default) to open its comms log. + Log Entry opens the entry pad: set the time once, then fire off quick actions — grouped Comms and Video, plus Warspite's priority buttons for nuclear authorization and Code Omega traffic — or type a manual entry. It stays open so a run of events is one tap each; close it with Done or Escape. Entries can be edited or deleted from the log, and ship details changed with the pencil in the header.
  4. Export — save your log as JSON to keep it beyond this browser, or generate a full formatted PDF report.
  5. Your log is saved in this browser automatically after every change, so a refresh or a crash won't lose it. Export the JSON if you need it on another device.
  6. Use + New Mission in the header to wipe the board and start fresh for a new session.
